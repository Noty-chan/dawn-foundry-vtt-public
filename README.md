# DAWN for Foundry VTT

An unofficial, standalone Foundry VTT system for DAWN: The RPG, LionWing edition. It includes English and Russian UI, hero creation, XD6 rolls, native compendiums, combat tools and shared clocks.

## Install

1. In Foundry **Setup → Game Systems → Install System**, paste the manifest URL:
   `https://github.com/Noty-chan/dawn-foundry-vtt-public/releases/latest/download/system.json`
2. Create a world using **DAWN — LionWing**.
3. Choose your language in Foundry’s core settings and reload the client. No system modules are required.

This preview targets Foundry V13, starting at build 351. Use a backup when upgrading an existing world. Experimental reactions and duels are off by default. Compound Enemy creation calculates shared statistics and lists part actions. The Narrator tracks separate part turns, gates and round expiry.

## Установка

1. В меню **Настройка → Игровые системы → Установить систему** вставьте ссылку на манифест:
   `https://github.com/Noty-chan/dawn-foundry-vtt-public/releases/latest/download/system.json`
2. Создайте мир на системе **DAWN — LionWing**.
3. Выберите язык в основных настройках Foundry и перезагрузите клиент. Дополнительные модули не требуются.

Предварительная сборка для Foundry V13, начиная со сборки 351. Перед обновлением существующего мира сделайте резервную копию. Экспериментальные реакции и дуэли выключены по умолчанию. Система рассчитывает общие параметры составных врагов и показывает действия частей. Ведущий отдельно ведёт ходы частей, пороги здоровья и снятие эффектов в конце раунда.
