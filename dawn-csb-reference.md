# Сравнение с Unofficial DAWN System

На 18 ноября 2026 скачан и прочитан [ev-ev-ev/dawn-statuses](https://github.com/ev-ev-ev/dawn-statuses/tree/07aceb6d263aab275b1ca6f3d13b220807fd5102). Это модуль для Custom System Builder 4.3.2. Его manifest указывает Foundry 12.331 и также требует Party Resources и Chat Commands. Проверка выполнена по исходникам и шаблонам.

| Возможность модуля | Эквивалент в нашей сборке | Граница |
| --- | --- | --- |
| Шаблоны героев и NPC, перетаскивание Техник | Нативные листы и компендии, конструктор героя, 111 Техник по трём уровням и 41 профиль NPC | Нужен прогон в чистом мире Foundry |
| Расчёт составного врага из нескольких компонентов | Форма создания актёра, общий максимум здоровья, модальный расчёт скорости, выбор защиты, вывод Пассивов и действий частей | Раздельные ходы, пороги и снятие эффектов в конце раунда пока ведутся ведущим |
| Макрос XD6 и объяснение броска | Листы, окно броска и карточка чата с расчётом XD6, Quick, критами, целью и Напряжением для поддержанных действий | Проверить отображение Dice So Nice отдельно |
| Макросы применения урона | Инструмент ведущего, план расчёта, подтверждение, здоровье и уклонение, защита от повтора | Особые случаи и составные враги требуют ручного разрешения |
| Пиктограммы состояний, действие Reinforced и Shredded | 19 состояний на нативном HUD. Reinforced пересчитывает броню, Shredded отменяет её для урона. Есть также обработчики части других состояний | HUD переключает состояние вручную. Сроки и пространственные последствия некоторых эффектов требуют отдельного управления |
| Напряжение сбрасывается, растёт по раундам и событиям Выведения героя | Нативное Напряжение, начало боя, переход раунда и сохранённый учёт Выведения. Настройка может автоматически учесть явную отметку defeated у героя | Повторное Выведение и снятие участника без отметки ведёт GM |
| Часы героя на листе. Общие часы через рекомендованный модуль | Общий виджет в инструментах сцены и личные часы владельца на вкладке неструктурированной игры | Синхронизация двух клиентов пока не проверена |
| Команда поиска по Тегам и выдача ссылок | Поиск по Тегам в библиотеке. Кнопка отправляет найденные UUID-ссылки пользователю в личный чат | Выдача ограничена 50 записями |
| Команды обновления актёров и шаблонных Items | Версионированная миграция прежних Техник и стабильные ID библиотеки | Общее управляемое обновление экземпляров с предварительным просмотром пока отсутствует |
| Инициатива с выбором очередного персонажа через рекомендованный Lancer Initiative | Выбор участника в нативном трекере и отдельное окно, ОД и защита целостности хода | Требуется проверка нескольких клиентов |

Выводы для разработки: держать быстрые состояния в HUD, использовать группы нативных Items для действий, показывать источники и модификаторы броска. Сопоставление экземпляров шаблона делать по ID, сохраняя пользовательские Тир, состояние и текст. Расчёт правил LionWing сверять с книгой. Для составных NPC использован раздел «Compound NPCs», PDF стр. 110.
